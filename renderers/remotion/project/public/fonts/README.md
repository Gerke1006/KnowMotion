# History serif font

`history-serif-heavy.otf` is the unchanged official **Source Han Serif SC Heavy**
static font from Adobe's [Source Han Serif 2.003R release](https://github.com/adobe-fonts/source-han-serif/releases/tag/2.003R),
pinned to commit `7889f11bf31170b5d092a083b357c8c8130f89e0`.
Only the local filename and the CSS alias `History Serif` differ; the font's bytes,
family names, copyright and reserved font name remain unchanged.

The font is distributed under the original [SIL Open Font License 1.1](OFL.txt).
Its copyright notice and complete license travel with the font in source,
Docker images and Python wheels. It may be embedded with the application under
that license; the font is not offered as a separately sold product.

`SOURCES.json` records the official immutable URLs, release, embedded names,
900 weight class, file sizes and SHA-256 fingerprints. The bundled license is
the original text at that same commit, including its original copyright years.

The design is a selected approximation of the requested heavy Song-style text.
It is not an assertion that a screenshot's exact typeface was identified. The
user's screenshot is not copied into the font assets or any video.

Verification used generic Chinese text and digits: every sampled character has
a glyph, the static OTF is readable by FreeType, and its metadata reports
`SourceHanSerifSC-Heavy`, version 2.003, weight 900. This is a font asset check,
not a video acceptance run.
